A deterministic program that writes one original funny line (101 characters) to `/output/entry.txt`: an AI asked to write wedding vows refuses on the grounds that, as an AI language model, it doesn't do commitment. Built for make.fun's "Make the Judge Laugh in One Line" bounty.

## Run it

```sh
python3 main.py
```

This writes the one-liner to `/output/entry.txt`. No randomness, no clock, no network — every run produces byte-identical output.
